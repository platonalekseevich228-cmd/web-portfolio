# ailajq — веб-портфолио

Портфолио одностраничных сайтов для частных специалистов и небольших услуг.

## Первый кейс

Демонстрационный лендинг репетитора математики: структура, тексты, адаптивный дизайн, HTML, CSS и JavaScript.

## Локальный запуск

Откройте `index.html` в браузере или запустите статический сервер из корня проекта.

Все демонстрационные проекты отмечены как учебные. В портфолио нет вымышленных клиентов и отзывов.
